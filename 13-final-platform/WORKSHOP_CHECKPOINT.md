# Step 13 - Final AI Engineering Skill Intelligence Platform

This is the complete workshop project combining the earlier checkpoints:

- Vite + React frontend
- Express backend
- MySQL persistence
- Random User learner creation
- JWT login
- Dashboard and topic selection
- Built-in and Gemini assessment generation
- Detailed results and explanations
- Saved Things to Learn roadmaps
- Roadmap progress tracking
- Targeted reassessment
- Progress/history
- Ranking
- AI mentor

For a fresh database, run only:

```bash
mysql -u root -p < server/sql/schema.sql
```

Then configure `server/.env` and run `npm install` / `npm run dev` from the root.
