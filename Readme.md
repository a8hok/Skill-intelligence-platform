
# AI Engineering Skill Intelligence Platform - Workshop Checkpoints

## Create a Vite project from scratch

```bash
npm create vite@latest 01-vite-setup -- --template react
cd 01-vite-setup
npm install
npm run dev
```

Alternative:

```bash
npx create-vite@latest 01-vite-setup --template react
```

## Checkpoints

1. 01-vite-setup - Vite + React foundation
2. 02-vite-express - Add Express backend
3. 03-vite-express-mysql - Add MySQL connectivity
4. 04-rest-api-connectivity - Connect React to Express REST API
5. 05-random-user-persistence - Random User API -> MySQL -> React
6. 06-user-login-jwt - User selection, JWT login, protected API
7. 07-dashboard-topics - Dashboard and topic selection
8. 08-basic-assessment - Built-in non-AI assessment and scoring
9. 09-gemini-assessment - Gemini + built-in assessment modes
10. 10-results-explanations - Correct answers and explanations
11. 11-learning-roadmap - Saved Things to Learn roadmap
12. 12-progress-reassessment - Progress tracking + targeted reassessment
13. 13-final-platform - Complete platform

Each checkpoint is intentionally a separate runnable project so students can move to the next known-good version if they fall behind during the workshop.
