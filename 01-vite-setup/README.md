# 01 - Vite Setup

## Create this project from scratch

```bash
npm create vite@latest 01-vite-setup -- --template react
cd 01-vite-setup
npm install
npm run dev
```

You can also use:

```bash
npx create-vite@latest 01-vite-setup --template react
```

## Learning goal
- What Vite is
- React entry point
- Components
- Development server
